# Images

This directory contains photographs and visual reference material for the Hydroponics Monitor.

Images added here should support the written documentation rather than duplicate it.

Useful subjects include:

- Raspberry Pi and Makerverse Protoboard stack
- RTC mounting
- completed protoboard top side
- completed protoboard underside
- terminal-block connections
- LED and alarm-inhibit switch mounting
- enclosure layout
- cable entry and strain relief
- completed controller installation
- sensor placement in the hydroponic system

## Construction Photos

Where possible, photographs should be taken before later assembly stages hide important wiring or solder connections.

Particularly useful photographs include:

- the protoboard before it is fitted to the Raspberry Pi
- the underside after all links and soldering are complete
- the GPIO header and RTC arrangement
- external sensor wiring before the enclosure is closed

## Published Images

Only images that accurately represent the verified build should be treated as authoritative reference material.

Planning images, temporary breadboard arrangements and superseded layouts may be retained during development, but should not be presented as final construction instructions.

The written connection details in [Wiring](../docs/wiring.md) remain authoritative if an image is unclear or appears inconsistent.
